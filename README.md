# Rural APS — static site (Cloudflare Pages)

Generated by build_site.py (Max Builds Websites). Plain HTML — edit pages directly, or edit the generator and re-run `python3 build_site.py`.

## Deploy
1. Push this folder to a GitHub repo (site files at repo root).
2. Cloudflare dashboard -> Workers & Pages -> Create -> Pages -> Connect to Git -> pick the repo.
3. Build command: none. Output directory: `/`. Deploy -> live at <project>.pages.dev.
4. Custom domain: add ruralaps.com.au + www once DNS is on Cloudflare (see cut-over plan).

## Before go-live checklist
- [ ] Replace FACEBOOK-PAGE-URL (contact.html, footer in every page) with the real Facebook URL
- [ ] Replace YOUR-WEB3FORMS-ACCESS-KEY in contact.html (create key at web3forms.com with ruralaps@hotmail.com)
- [ ] Drop real photos into gallery + service page tops; add alt text
- [ ] Supply logo to replace the "R" mark in the header
- [ ] Verify phone/email
- [ ] Submit sitemap.xml in Google Search Console after DNS cut-over

## Local preview
`python3 -m http.server` in this folder, then http://localhost:8000 — links are root-relative, so don't open files directly with file://.
